## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-select-download-folder`
- `allow-select-send-document`
- `allow-select-send-folder`
- `allow-consume-share-intent`
- `allow-cancel-job`
- `allow-export-to-tree`
- `allow-open-download-folder`
- `allow-export-to-media-store`
- `allow-open-download-target`
- `allow-get-window-insets`
- `allow-start-presence-service`
- `allow-stop-presence-service`
- `allow-write-text-to-uri`
- `allow-fetch-update-manifest`
